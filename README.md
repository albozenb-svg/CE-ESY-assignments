المخزن الدائري:
هو عبارة عن مصفوفة ثابتة الحجم عند الوصول لنهايتها نعود للبداية

المتغيرات:
 buffer : مصفوفة التخزين
 head : مؤشر القراءة
 tail : مؤشر الكتابة
 count : عدد العناصر الموجودة

الدوال:
isFull(): تعيد true إذا كان المخزن ممتلئاً
isEmpty(): تعيد true إذا كان المخزن فارغاً

write(): تضع الحرف في موقع tail، ثم تقدم tail بشكل دائري وتزيد count.
إذا كان المخزن ممتلئاً تطبع "Overflow".

read(): تأخذ الحرف من موقع head، ثم تقدم head بشكل دائري، وتنقص count.
 إذا كان فارغاً ترجع \0.

main(): تطلب إدخال اسم وتكتبه في المخزن، ثم تقرأه وتعرضه وتتأكد في النهاية أن المخزن فارغ 

الدوران الدائري:
يتم باستخدام (i + 1) % SIZE لإعادة المؤشر للبداية عند الوصول للنهاية

الحالات الخاصة
 Overflow: رفض الكتابة عند الامتلاء
 Underflow: إرجاع \0 عند القراءة من مخزن فارغ
